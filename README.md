# AI Fraud Detection System 
An AI powered Financial Fraud Detection and Risk Analytics Platform built using Machine Learning, Flask, HTML, CSS, and Python.

# Features

 AI-powered fraud detection  
 Random Forest Machine Learning model  
 Fraud probability analysis  
 Risk monitoring system  
 Interactive analytics dashboard  
 Transaction reports page  
 Fraud visualization charts  
 Responsive UI design  
 CSV dataset upload support
